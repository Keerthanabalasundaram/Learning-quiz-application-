📚 Learning Quiz App

The Learning Quiz App is an adaptive, gamified quiz platform designed to make studying interactive and exam-ready. It generates MCQs from user-uploaded study material while also offering an inbuilt unit-wise question bank. With features like timers to simulate real exam conditions, level-based progression across topics, and dynamic difficulty adjustment that adapts to each learner’s performance, the app ensures personalized growth. Learners are motivated through congratulatory animations when they succeed and uplifting visuals when they need encouragement, while detailed result analytics track progress and highlight strengths for a smarter, confidence-boosting learning experience.
